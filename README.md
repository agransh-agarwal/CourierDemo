# Courier Demo App: mobile release process project

A personal learning project to practise the mobile release process for an iOS app, end to end.

The app itself is intentionally simple (Apple's SwiftUI template showing the app name and version). The focus is the release process around it.

## What this project covers

- **Release planning in Jira:** Scrum board, epic, 11 work items, sprint and release version 1.0.0
- **Versioning:** version 1.0.0, build 1, minimum supported iOS 17.0
- **Testing:** automated unit and UI tests in Xcode, manual smoke test in the iOS Simulator and on a physical iPhone
- **CI/CD:** automated build with GitHub Actions on every push (in progress)
- **Release documentation:** release checklist and release notes (in progress)

## Tools

Xcode, Swift/SwiftUI, iOS Simulator, Git, GitHub, GitHub Actions, Jira
